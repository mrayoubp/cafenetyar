# رابط React کافی‌نت‌یار

این رابط به API داخلی همان دامنه متصل است و SDK بک‌اند خارجی ندارد. سرور مستقل و راهنمای انتشار در ریشهٔ مخزن هستند: [راهنمای لینوکس](../docs/LINUX-HOSTING.md).

```bash
npm ci
npm run build
npm test
```

برای خروجی کامل سرور و رابط از `npm run build` ریشهٔ پروژه استفاده کنید. فقط کپی‌کردن خروجی Vite، بک‌اند و دیتابیس را اجرا نمی‌کند.

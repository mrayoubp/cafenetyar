# کافی‌نت‌یار — بک‌اند مستقل لینوکس

نسخهٔ ۴ همان رابط فارسی React را با بک‌اند داخلی و SQLite اجرا می‌کند. ورود، حساب مشتریان، حسابداری، کالا و انبار، نرخ‌نامه، خبرها و سامانه‌ها، پشتیبانی و دستیار محلی به سرویس Convex وابسته نیستند.

- **هاست:** Node.js 24 با دیسک پایدار، یا سرور لینوکس؛ اجرای زمان نصب به MySQL و سرویس ابری دیگری نیاز ندارد.
- **بستهٔ آماده:** `dist/releases/cafenetyar-linux-4.0.0.zip` پس از build و package ساخته می‌شود؛ artifact خصوصی GitHub Actions نیز آن را دارد.
- **نصب و انتقال:** [راهنمای فارسی لینوکس](docs/LINUX-HOSTING.md).
- **حساب‌ها:** [ورود مستقل و مدیریت مالک](docs/PRIVATE-ACCOUNTS.md).

```bash
npm run setup
npm run build
npm test
npm run package:linux
```

بستهٔ زمان اجرا شامل سرور Node، رابط کامل، migrationها، نصب وب با کد خصوصی، فرمان ساخت مالک، پشتیبان‌گیری و بازیابی است. رمز و دیتابیس شخصی داخل بسته نیست. با `npm start` اجرا می‌شود؛ روی پنل‌های Node، فایل شروع `app.cjs` نیز موجود است.

ثبت‌نام عمومی بسته است و فقط مالک حساب می‌سازد. پلن یک‌ماههٔ ۵۰۰هزار تومان و خرید از تلگرام `@Cafenetyarr` حفظ شده‌اند. پیامک و درگاه پرداخت خودکار متصل نیستند. دستیار محلی از محتوای ذخیره‌شده و نرخ‌های معتبر همین کافی‌نت استفاده می‌کند؛ مدل تولید متن خارجی متصل نیست.

میزبانی فعلی Sites همین بک‌اند را با D1 اجرا می‌کند تا نسخهٔ موجود قابل استفاده بماند. بستهٔ لینوکس از SQLite خود سرور استفاده می‌کند و به Sites یا Cloudflare نیاز ندارد. `.openai/hosting.json` شناسهٔ همان سایت موجود را نگه می‌دارد.

داده‌های دوردستی که فقط در بک‌اند قبلی مانده‌اند بدون خروجی آن سرویس خودبه‌خود منتقل نمی‌شوند. داده‌های D1 فعلی حذف نشده‌اند؛ پشتیبان کامل JSON و واردکردن دفتر مالی از فایل در پنل مالک آماده است. نسخهٔ قبل از جداسازی در تاریخچهٔ گیت محفوظ است.

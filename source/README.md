# برنامهٔ اصلی کافی‌نت‌یار

این پوشه برنامهٔ React/Vite و کد Convex پروژهٔ اصلی است. راهنمای نسخهٔ جاری، پنل مدیریت، نصب و انتشار در [README اصلی](../README.md) قرار دارد.

در پوشهٔ اصلی مخزن، `npm run setup`، سپس `npm run build` و `npm test` را اجرا کنید. برای توسعهٔ رابط، تنظیمات `source/.env.example` را در `source/.env.local` قرار دهید و داخل همین پوشه `npm run dev` بزنید.

پنل فعلی از `/manage` روی سرور Worker اجرا می‌شود. داده‌های قدیمی حسابداری و کاربران هنوز در Convex قبلی‌اند. پوشهٔ docs و ADMIN-ROLLOUT.md گزارش‌های تاریخی‌اند؛ آن‌ها را تأیید اتصال یا استقرار فعلی تلقی نکنید.

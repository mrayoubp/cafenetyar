# کافی‌نت‌یار

کد کامل نسخهٔ فعلی سایت، پنل مدیریت، سرور، ساختار دیتابیس و آزمون‌ها.

- سایت: https://kafinetyar-live-nov15.valiantlute16.chatgpt.site
- مدیریت: https://kafinetyar-live-nov15.valiantlute16.chatgpt.site/manage
- مخزن: https://github.com/mrayoubp/cafenetyar
- خرید و تمدید: https://t.me/Cafenetyarr
- تنها پیشنهاد خرید: اشتراک یک‌ماهه، ۵۰۰٬۰۰۰ تومان؛ هماهنگی پرداخت و فعال‌سازی در تلگرام.

## اجرا و ساخت

Node.js نسخهٔ ۲۴ یا جدیدتر و npm لازم است. در پوشهٔ اصلی مخزن اجرا کنید:

```sh
npm run setup
npm run build
npm test
```

ساخت نهایی در `dist/server/index.js` قرار می‌گیرد. پنل و API به Cloudflare Worker و دیتابیس D1 با نام اتصال `DB` نیاز دارند. باز کردن فایل HTML به‌تنهایی سرور را اجرا نمی‌کند. برای تغییر ظاهر با Vite می‌توانید در پوشهٔ `source` از فایل `.env.example` یک `.env.local` بسازید و `npm run dev` را اجرا کنید؛ پنل و API در سرور منتشرشده فعال‌اند. نسخهٔ توسعهٔ Vite به‌تنهایی جایگزین محیط کامل سرور نیست.

## بخش‌های پروژه

| مسیر | کاربرد |
| --- | --- |
| `source/src` | برنامهٔ اصلی React، صفحات، حسابداری و کد Convex قبلی |
| `native` | سرور و رابط پنل مدیریت، خبرها و بانک سامانه‌ها |
| `drizzle` | تغییرات افزایشی دیتابیس D1 |
| `scripts` | ساخت برنامهٔ اصلی و بستهٔ نهایی سرور |
| `dist/server` | خروجی قابل انتشار همان نسخه |
| `.openai/hosting.json` | شناسه و اتصال دیتابیس همین سایت در Sites |

صفحهٔ اصلی و مسیرهای داشبورد، برنامهٔ اصلی‌اند. `/manage` پنل مدیریت است و `/admin` به آن هدایت می‌شود. فایل `native/server.mjs` را به‌تنهایی منتشر نکنید؛ انتشار از `native/composed-server.mjs` انجام می‌شود تا سایت اصلی و پنل با هم کار کنند.

## مدیریت محتوا

با حساب ChatGPT مالک وارد `/manage` شوید و تأیید دومرحله‌ای را انجام دهید. از «تنظیمات و لوگو» نام، نشان، تیتر صفحهٔ اصلی و تماس را تغییر دهید. خبر، مقاله و سامانه را از «محتوای سایت» ویرایش کنید. «ذخیره پیش‌نویس» فقط در پنل ذخیره می‌کند؛ «ذخیره و انتشار در سایت» محتوا را در سایت نشان می‌دهد. خبرها و سامانه‌ها، از جمله پیش‌نمایش داشبورد، از یک منبع خوانده می‌شوند.

اطلاعات جدید در D1 ذخیره می‌شوند و با انتشار دوباره پاک نمی‌شوند. مخزن گیت‌هاب شامل کد و ساختار دیتابیس است؛ اطلاعات کاربران، نشست‌های ورود، کلیدهای محرمانه و داده‌های زنده در آن قرار ندارند. بکاپ دادهٔ زنده باید جداگانه و در فضای خصوصی نگهداری شود.

## تنظیمات سرور و محدودیت‌های فعلی

`OWNER_EMAIL` ایمیل مالک برای راه‌اندازی اولیهٔ امن پنل و `OWNER_PHONE` شمارهٔ تماس است. آن‌ها را در تنظیمات محرمانهٔ میزبان ثبت کنید، نه داخل کد یا گیت‌هاب. ورود مالک به پنل، نشست و تأیید دومرحله‌ای لازم دارد.

حساب‌ها، حسابداری، اشتراک‌ها، ایجنت و تیکت‌های برنامهٔ اصلی هنوز به Convex قبلی متصل‌اند. پنل جدید نمی‌تواند کاربران یا اشتراک‌های آن سرور را تغییر دهد. استقرار کد Convex جدید یا فعال‌سازی اشتراک قدیمی نیازمند دسترسی مالک به همان سرور است. کلید Convex قبلی در اختیار این پروژه نیست.

سرویس پیامک و درگاه پرداخت متصل نیستند. دکمهٔ خرید گفت‌وگوی تلگرام را با متن آماده باز می‌کند؛ مشتری پیام را ارسال می‌کند و فعال‌سازی خودکار انجام نمی‌شود. سامانه‌ها و مقاله‌ها دستی به‌روز می‌شوند. دسترسی عمومی سایت در Sites با درخواست مالک فعال شده است؛ عملیات مدیریتی همچنان ورود و مجوز لازم دارد.

جزئیات فنی انتشار و بررسی‌ها در [native/ROLLOUT.md](native/ROLLOUT.md) و [docs/RELEASE-2026-11-17.md](docs/RELEASE-2026-11-17.md) است. پوشهٔ `source/docs` شامل گزارش‌های تاریخی پروژهٔ قبلی است؛ وضعیت نسخهٔ فعلی را از همین راهنما بخوانید.

## اجرای موقت روی Cloudflare

پیکربندی Worker و D1 در `wrangler.jsonc` و راهنمای اتصال مخزن و انتشار در [cloudflare/README.md](cloudflare/README.md) آماده است. ورود پنل در این میزبان به Cloudflare Access نیاز دارد. انتقال خودکار اطلاعات زندهٔ میزبان قبلی انجام نمی‌شود.

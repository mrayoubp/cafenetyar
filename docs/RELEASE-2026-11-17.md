# بررسی نسخهٔ ۲۶ آبان ۱۴۰۵

## نتیجهٔ بررسی

- برنامهٔ اصلی React و مسیرهای حسابداری، کارمندان، نرخ‌نامه و ایجنت در سایت حفظ شده‌اند؛ پنل در `/manage` اجرا می‌شود.
- پیش‌نمایش خبرها و سامانه‌ها در داشبورد به همان منبع مدیریت‌شدهٔ صفحات کامل وصل شد. تغییرات منتشرشده در هر دو محل دیده می‌شوند؛ پیش‌نویس نمایش داده نمی‌شود.
- دکمه‌های «ذخیره پیش‌نویس» و «ذخیره و انتشار در سایت» جدا هستند. خطا داخل پنجرهٔ ویرایش نمایش داده می‌شود و محتوای منتشرشده لینک مشاهده دارد.
- قیمت جاری یک ماه، ۵۰۰ هزار تومان است. خرید و تمدید، گفت‌وگوی `@Cafenetyarr` را با متن آماده باز می‌کند. این اقدام پیام ارسال نمی‌کند و پرداخت یا فعال‌سازی خودکار نیست.
- نوار و افزونهٔ سایت‌ساز قبلی از خروجی رابط حذف شدند. وابستگی قدیمی AI که زنجیرهٔ آسیب‌پذیر داشت با یک رابط کوچک HTTP برای همان API جایگزین شد. این تغییر کد، استقرار سرور Convex قبلی محسوب نمی‌شود.
- فایل قفل npm، فایل‌های تولیدشدهٔ لازم Convex، دستورهای ساخت از ریشه، تنظیمات نمونهٔ عمومی و آزمون GitHub Actions اضافه شدند. اطلاعات محرمانه در نمونهٔ تنظیمات قرار ندارد.
- مسیر دانلود کد به مخزن نسخهٔ جاری وصل شد؛ درخواست favicon به نشان موجود هدایت می‌شود.

## شواهد اعتبارسنجی

- ساخت TypeScript و Vite و بستهٔ نهایی Worker موفق بود.
- ۵۲ آزمون برنامهٔ اصلی و رابط AI، و ۲۰ آزمون سرور، جداسازی داده، مجوزها، انتشار و مسیرهای اصلی موفق بودند.
- در یک پوشهٔ تمیز، فقط فایل‌های مخزن استخراج و وابستگی‌ها از `source/package-lock.json` نصب شدند. ساخت و هر ۷۲ آزمون دوباره موفق بودند؛ SHA-256 خروجی Worker با نسخهٔ انتشار برابر است. فایل قفل به مسیرهای محلی این محیط وابسته نیست.
- `npm audit` روی نصب کامل، صفر هشدار ثبت کرد. این نتیجه، تضمین نبودن همهٔ آسیب‌پذیری‌ها نیست.
- اسکن الگوهای شناخته‌شدهٔ کلید محرمانه در کد و تاریخچه و ZIPها موردی پیدا نکرد؛ این بررسی جای بررسی همهٔ انواع اطلاعات حساس را نمی‌گیرد.
- پاسخ عمومی Convex برای مشخصات، محتوای سایت و ناوبری موفق بود. خواندن کاربر و زمینهٔ حساب در حالت خروج، `null` برگرداند. عملیات حساب‌های واقعی یا مالی کاربران در این بررسی انجام نشد.
- آزمون بسته تأیید می‌کند مسیر اصلی و صفحات داشبورد دقیقاً HTML برنامهٔ اصلی را دریافت می‌کنند؛ پنل جای آن‌ها قرار نمی‌گیرد. محتوای فایل ورودی JavaScript با خروجی Vite برابر است.

مرورگر آزمایشی در این محیط در دسترس نبود. ورود واقعی کاربران قدیمی، ارسال پیامک، پرداخت و فراخوانی زندهٔ AI آزمایش نشده‌اند. آزمون رابط AI از پاسخ‌های شبیه‌سازی‌شده استفاده می‌کند و هیچ درخواست پولی نفرستاده است.

## موارد لازم برای عرضه به مشتریان

سایت در Sites همچنان خصوصی و مخصوص مالک است. دسترسی عمومی باید جداگانه توسط مالک تعیین شود.

داده و کنترل کاربران، اشتراک‌ها، حسابداری و تیکت‌های قدیمی در Convex قبلی باقی مانده‌اند. مالک برای استقرار تغییرات سرور یا فعال‌سازی اشتراک قدیمی به دسترسی مدیریتی آن پروژه نیاز دارد. پنل جدید حساب‌های D1 را مدیریت می‌کند و نمی‌تواند اشتراک Convex را فعال کند. اتصال یا مهاجرت این بخش پیش از اتکا به فروش و فعال‌سازی اشتراک لازم است.

سرویس پیامک و درگاه پرداخت هنوز متصل نیستند. هماهنگی خرید با تلگرام انجام می‌شود. بکاپ کد گیت‌هاب شامل دادهٔ زندهٔ D1 یا Convex نیست؛ بکاپ دیتابیس‌ها باید در محل خصوصی جداگانه تهیه و بازگردانی آن آزمایش شود.
